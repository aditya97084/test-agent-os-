# raw/ — immutable sources

Everything here is captured verbatim from public material. **No agent may edit, reformat,
"clean up" or delete anything in this folder.** It is the source of truth that every wiki
quote must be traceable to.

Layout (one folder per source type, one crawler subagent per folder):

```
raw/youtube/   captions, timestamped, one file per video
raw/blog/      posts converted to markdown
raw/github/    READMEs / docs from his repos
raw/x/         posts, one file per year
raw/papers/    pdfs + extracted text
raw/misc/      manual clips (Obsidian Web Clipper), podcast transcripts
raw/MANIFEST.md  generated by scripts/crawl_report.py — audit the crawl here
```

Every file starts with frontmatter: `title, url, date, source_type, word_count, fetched_at`.

Contents are gitignored by default (size + third-party content). The wiki built from them is
what gets committed.
