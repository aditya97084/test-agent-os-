# Wiki invariants

1. `raw/` is **immutable**. Read it. Never edit, move, reformat or delete a file in it.
2. `wiki/` is **yours**. You create and maintain every page there; the human only reads it.
3. Every factual claim about Andrej Karpathy must be backed by a verbatim quote from a file in
   `raw/`, with a link to its `wiki/sources/<slug>.md` page. If no quote exists, write
   `> INFERRED: no direct quote; extrapolated from [[...]]`. Never invent a quote or a timestamp.
4. Links are `[[path/slug]]` and bidirectional. No page ships without inbound links and an
   `index.md` entry, created in the same turn.
5. Every mutation of `wiki/` ends with: index updated + `wiki/log.md` appended as
   `## [YYYY-MM-DD] <operation> | <title>`.
6. One source normally touches 5–15 pages. Writing only a source page is an incomplete ingest.
7. Contradictions are never silently resolved. Record both claims under `## Contradictions`
   with their sources and ask the human.
8. `wiki/_graph/*` is generated by `scripts/build_graph.py`. Never hand-edit it.
